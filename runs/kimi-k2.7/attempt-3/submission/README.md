# Neon Keygen

An original keygen-style chiptune composed in FastTracker II.

- **Tempo:** 150 BPM, speed 6
- **Key:** E minor
- **Progression:** Em → C → G → D (with an Am variation)
- **Style:** driving square-wave lead, saw bass, pulse arpeggios, noise drums

All sounds are generated from short samples and sequenced with tracker patterns and effects (arpeggios, note cuts). No long prerendered audio is used.

Files:
- `tune.xm` – final editable XM module
- `tune_preview.wav` – rendered stereo preview
- `make_tune.py` – Python/NumPy script that generates the samples and builds the module
