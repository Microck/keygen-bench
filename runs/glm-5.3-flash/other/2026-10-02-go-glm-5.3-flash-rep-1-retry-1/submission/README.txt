AMETHYST KEYGEN  -  original tracker tune (FastTracker II / XM)
=================================================================

FILE           tune.xm        XM module: 12 channels, 18 instruments, 14 patterns
FORMAT         Extended Module v1.04, 16-bit mono samples, linear frequency table
TEMPO          150 BPM, speed 6  ->  10 rows/sec, 16 rows per bar, 64 rows = 4 bars
LENGTH         89.6 s total.  Patterns 0-1 are a one-shot intro; the tune then
               loops forever over patterns 2-13 (a 76.8 s loop).
               Restart / loop position = 2, order = 0,1,2,...,13
KEY / CHORDS   A minor -  Am | F | C | G   (one bar per chord, 4 bars per pattern)
preview.wav    44.1 kHz stereo 16-bit render of one full pass; the music returns
               to pattern 2 at 12.8 s, which is how it loops in the module
LEVELS         peak 0.95 FS, programme RMS -16 dBFS, no clipping

ARRANGEMENT
  p0  intro        kick + hats + arp, bass/chords join in bar 3, noise riser bar 4
  p1  intro II     clap added, snare-roll fill
  p2  A1           groove: kick/snare/hats, 8th bass, offbeat chord stabs, 8th arp
  p3  A2           16th arpeggio version
  p4  B1           lead melody enters (harmony kept low)
  p5  B2           lead continues, tom fill
  p6  C1           chorus - harmony in 3rds/6ths, bell accents, crash
  p7  C2           chorus, fill
  p8  break        pads + bell only, sparse kick/clap, no backbeat
  p9  build        full groove, 8th then 16th snare roll, noise riser
  p10 D1            chorus variation, new melody
  p11 D2            variation, fill
  p12 E1            final chorus, main hook + bell
  p13 E2            hook resolves onto the tonic, turnaround fill -> loops to p2

SOUND PALETTE (every sample synthesised from scratch with NumPy; no envelopes or
patch data are used, the shaping is baked into the audio itself)
   1 KICK          pitch-swept sine body 170 -> 44 Hz + filtered click, tanh drive
   2 SNARE         band-passed noise + 186/331 Hz tone
   3 CLAP          triple noise burst with a longer tail
   4 CHAT / 5 OHAT high-passed noise, 60 ms / 340 ms
   6 CRASH         filtered noise with inharmonic partials
   7 TOM           280 -> 90 Hz sine sweep
   8 RISER         rising band-passed noise
   9 BASS          saw + square + sub-octave sine, swept low-pass, pluck decay
  10-13 STAB_AM/F/C/G  four-voice detuned-saw chord stabs (pre-voiced)
  14 PAD          detuned saws + triangle, attack baked in, seamless forward loop
  15/16 LEAD,LEAD2  bright pulse/saw lead, seamless loop, doubled in harmony
  17 BELL         additive inharmonic partials
  18 ARP          short pulse pluck for the arpeggios

TRACKER TECHNIQUE
  - offbeat 8th chord stabs played against a four-on-the-floor kick
  - 16th closed hats, with open hats replacing the offbeat 8ths
  - the last chord stab of every four-bar phrase carries an 0xy arpeggio command
    (037 / 047) so the whole chord riffs through its triad as a flourish
  - the 16th arpeggio ping-pongs between the left and right side (8xx panning
    on alternate rows)
  - sustained lead/pad/harmony notes are looped samples; each one is released
    with a two-stage volume-column slide (68 then 6F) so the channel reaches
    true silence before the next note and before the loop point
  - 4xy vibrato on lead, harmony and pad
  - panning baked per sample: closed hat left, open hat/arp right,
    kick/bass/lead/chords centre - the whole mix stays mono-compatible
  - samples start and end on zero (short fades) and are DC-blocked, so there are
    no ticks on triggers and no DC thumps

All material was generated by the Python sources in src/:
  dsp.py       DSP helpers (filters, waveforms, seamless loop crossfade)
  samples.py   the synthesis of all 18 instruments
  song.py      harmony, melodies, drum patterns and the full arrangement
  emit.py      writes the module through the FT2 tool (samples + 3300 pattern cells)
  patterns.txt a text dump of the complete score
