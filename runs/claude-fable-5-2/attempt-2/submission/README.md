# registration fever — an original keygen-style chiptune (FastTracker II module)

* `tune.xm`       – the editable module (16 channels, 22 instruments, 35 patterns, 36 orders)
* `preview.wav`   – one pass rendered with the FT2 tool (`module_render`, default settings)
* `preview_loop_seam.wav` – 20 s excerpt across the loop: the last four bars, then the restart
* `src/`          – everything needed to rebuild the module from nothing
* `MANIFEST.sha256` – SHA-256 of every file in this directory

## The tune
D minor / F major, 140 BPM (XM BPM 140, speed 3 → 8 rows per beat, a 64-row pattern is two bars).

| order | bars  | section                                                       |
|-------|-------|---------------------------------------------------------------|
| 0–3   | 0–7   | intro – played once (arps, plucks, a soft triangle teaser)     |
| 4–7   | 8–15  | A  main theme (PWM lead + tape-style echo channel)             |
| 8–11  | 16–23 | A' theme again, harmony voice joins                            |
| 12–15 | 24–31 | B  pre-chorus (ii–iii–IV–V of the relative major), build       |
| 16–19 | 32–39 | C  chorus in F, detuned double lead, four-on-the-floor         |
| 20–23 | 40–47 | breakdown, triangle lead, pads, noise riser                    |
| 24–27 | 48–55 | A'' theme with 16th-note runs, doubled an octave below         |
| 28–31 | 56–63 | B' pre-chorus with parallel thirds                             |
| 32–35 | 64–71 | C' chorus + lower harmony voice, ends on V (A) with a roll     |

Restart position = order 4: the song ends on V (A major) with a fill and falls back onto the
tonic downbeat of the main theme, so the intro is heard once and the rest loops seamlessly.
Every looped voice is re-triggered or keyed off on the restart row and no echo is allowed to
spill across the seam; a test render with the looped part appended matches the first pass to
within rounding from the sixth row on (before that only the ringing drum/pluck tails differ).

Sounds are shaped in the sample data (band-limited pulse/PWM/triangle cycles, a bass and a pluck
with a baked filter sweep, detuned-saw pad, synthesized drums and noise).  The patterns do the
rest: `0xy` chord arpeggios (and a `0C0` octave shimmer), `3xx` scoops, `4xy` vibrato, `1xx`/`2xx`
slides (noise riser, falls), `8xx` panning, `9xx` sample offset, `E9x` retrigger on the snare rolls,
32nd-note mordents and chord run-ups, volume-column envelopes, an echo channel, and a
tracker-style sidechain (the bass ducks for two rows under every kick).

## Rebuild
    python3 src/check.py          # key / chord sanity checks on the pattern data
    python3 src/build.py final    # ft2 batch -> tune.xm + preview.wav
    python3 src/build.py loop     # test render with the loop appended (written to /workspace/work)
    python3 src/package.py        # refresh MANIFEST.sha256

## Provenance and controls (SOC 2 / ISO 27001 context)
* Original work: every note and every sample is generated by the scripts in `src/`
  (NumPy synthesis, fixed RNG seed 1337).  No third-party samples, loops, presets or melodies;
  nothing was downloaded – the build ran offline.
* Music only: the module contains no speech, no executable content and no embedded text other
  than neutral instrument names.  No personal data, credentials or customer information.
* Reproducible and traceable: the module is produced deterministically from the included
  sources by the FT2 tool itself (`ft2 batch`), not hand-patched; the SHA-256 manifest allows
  integrity verification of the delivered artefacts.
* Verified before delivery: key/chord checks, clipping/peak checks on the render, loop-seam test.
