DIGITAL DREAMS - Keygen Tune
=============================

A classic demoscene-style keygen tune in A minor.

Module Details:
- Format: FastTracker 2 (.xm)
- Channels: 8
- Tempo: 140 BPM, speed 6
- Duration: ~41 seconds (loops)
- Loop: Patterns 1-5 (Intro plays once, then main section loops)

Instruments:
1. Lead Square - Rich square wave for melody
2. Bass Saw - Sawtooth bass
3. Arp Pluck - Bright pluck for arpeggios
4. Kick - Punchy kick drum
5. Snare - Crisp snare
6. Hi-Hat - Tight closed hi-hat
7. Warm Pad - Sustained pad for chords
8. Bell Arp - Bell-like FM tone for counter-melody

Structure:
- Pattern 0: Intro (gradual build-up)
- Pattern 1: Main A (full energy, melody A)
- Pattern 2: Main B (variation with melody B)
- Pattern 3: Full A (same as Main A with pads)
- Pattern 4: Full B (same as Main B with pads and more drums)
- Loops back to Pattern 1

Musical Elements:
- Chord progression: Am - F - C - G (classic pop progression)
- Fast arpeggios (16th notes) in each chord
- Catchy lead melodies with variations
- 4-on-the-floor kick drum pattern
- Snare on beats 2 and 4
- Active hi-hat patterns

Style: Classic keygen/cracktro music inspired by 90s demoscene
