PROMETHEUS KEYGEN
=================

An original keygen-style tracker tune.

Technical details:
- Format: FastTracker II (.xm)
- 8 channels, 12 instruments
- Tempo: 132 BPM, speed 6
- Length: 10.89 seconds per loop
- 6 patterns × 16 rows = 96 rows total

Chord progression (vi-IV-I-V-ii-vi):
- P0: Am
- P1: F
- P2: C
- P3: G
- P4: Dm
- P5: Am (returns to start for clean loop)

Instruments:
1.  Lead - square wave with vibrato
2.  Pluck - triangle with harmonics
3.  Pad - sawtooth + sub sine + octave square
4.  Bass - sub square + sine
5.  Kick - body + click transient
6.  Snare - noise + body
7.  Closed hat - short noise burst
8.  Open hat - longer noise burst
9.  Crash - high-pass filtered noise
10. Tom - pitched sine with envelope
11. Organ - sine stack (chord arpeggio)
12. Arp - short triangle pluck (counter-melody)

Files:
- tune.xm: the tracker module
- preview.wav: 1-loop preview render (10.89s)
- preview_long.wav: 3-loop preview render (32.68s) for inspection
- build_module.py: Python script that builds the module
- gen_samples.py, fix_samples.py, fix_samples2.py: sample generation scripts

To listen: load tune.xm in FastTracker II, OpenMPT, or similar tracker.
