Keygen Tune - Original Tracker Music
=====================================
Composed for FastTracker II (XM format).

Structure:
- Pattern 0: Intro (4 bars)
- Pattern 1: Main A (4 bars)
- Pattern 2: Main B (4 bars)
- Pattern 3: Main C (4 bars)
- Pattern 4: Outro/Fill (4 bars)
- Loop starts at order 1 (Main A) for seamless looping.

Instruments:
1. Kick drum (sine sweep + decay)
2. Snare drum (noise + tone burst)
3. Closed hi-hat (high-passed noise, short)
4. Open hi-hat (high-passed noise, longer)
5. Bass (looped square wave with attack click)
6. Lead (looped detuned saw wave, 4 cycles)
7. Pluck/Bell (sine with harmonics, decay)

Effects used:
- Arpeggio (0xy) on channel 5 for chord texture.
- Volume column for dynamic accents.
- Panning set per instrument for stereo width.

BPM: 150, Speed: 6, Channels: 8
Key: D minor
