Keygen Dreams - Original Keygen Tune
=====================================

A chiptune-style keygen music module created with FastTracker II.

Structure:
- 8 channels
- 135 BPM, Speed 6
- 2 patterns (64 rows each)
- Order: Pattern 0 -> Pattern 1 -> Pattern 0 (loops)
- Key: A minor

Instruments:
1. Lead - Bright sawtooth synth
2. Bass - Punchy synth bass
3. Chord - Soft pad
4. Kick - Synth kick drum
5. Snare - Noise-based snare
6. Hi-Hat - High-frequency noise

Channel Layout:
0: Main melody
1: Harmony/counter-melody
2: Bass line
3: Chord hits
4: Kick drum
5: Snare drum
6: Hi-hat
7: Arpeggio

The tune features a catchy, repetitive melody typical of keygen music,
with a driving four-on-the-floor beat and arpeggiated accompaniment.
