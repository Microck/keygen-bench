# References

Access date for web sources: 2026-09-04.

Primary and official sources are preferred. A public archive is used as corpus evidence, not as universal history.

## S01

MilkyTracker project. “MilkyTracker Manual v1.05.1.”  
https://milkytracker.org/docs/manual/MilkyTracker.html

Use: tracker structure, MOD/XM focus, sample editor, waveform generation, effects, instruments, optimization, playback compatibility.

## S02

MilkyTracker project. “About.”  
https://milkytracker.org/about/

Use: concise official statement that MilkyTracker creates MOD and XM and recreates the FT2 experience.

## S03

OpenMPT project. “Manual: Module formats.”  
https://wiki.openmpt.org/Manual:_Module_formats

Use: MOD/XM/S3M/IT capabilities, instruments, envelopes, panning, filters, New Note Actions, compression, format-selection guidance.

## S04

OpenMPT project. “Manual: Effect Reference.”  
https://wiki.openmpt.org/Manual:_Effect_Reference

Use: MOD/XM versus S3M/IT effect families and tracker-effect semantics.

## S05

OpenMPT project. “Manual: Cleanup Manager.”  
https://wiki.openmpt.org/Manual:_Cleanup_Manager

Use: removal/rearrangement of unused patterns and other module cleanup.

## S06

OpenMPT project. “Development: Formats/IT.”  
https://wiki.openmpt.org/Development:_Formats/IT

Use: IT creation-version fields and warning that other trackers may imitate Impulse Tracker identifiers.

## S07

8bitbubsy. “ft2-clone: Fasttracker II clone for Windows/macOS/Linux.”  
https://github.com/8bitbubsy/ft2-clone

Use: original-source-derived XM replay, FT2 compatibility, trim function, supported sample and module operations.

## S08

8bitbubsy. “pt2-clone: ProTracker 2 clone for Windows/macOS/Linux.”  
https://github.com/8bitbubsy/pt2-clone

Use: faithful ProTracker 2.3D reconstruction and Amiga-oriented playback behavior.

## S09

Jeffrey Lim. “impulse-tracker: Original source code for Impulse Tracker.”  
https://github.com/jthlim/impulse-tracker

Use: original tracker source, pattern and instrument editors, playback, sample compression, DOS toolchain.

## S10

uFMOD project. “uFMOD: XM player library written in assembly language.”  
https://ufmod.sourceforge.io/

Use: compact XM playback, size-critical purpose, supported effects, compressed samples, XMStrip, platform audio backends.

## S11

Firelight Technologies historical MiniFMOD material, maintained mirror. “MiniFMOD 2.2.0 C++ version.”  
https://github.com/SpinningKids/minifmod

Use: XM-only static replay, memory/resource loading, player-size optimization, effect stripping, synchronization.

Caveat: repository is a maintained mirror/refactor that preserves original historical documentation. Historical footprint figures are project claims.

## S12

## Source-selection notes

- Wikipedia and secondary summaries were used only for discovery and were not required for the core findings.
- Exact scene-group preferences are omitted unless direct source or module evidence is available.
- Tool release dates are stated only where the project itself or original source history supports them.
- No source is interpreted as granting a license to redistribute archived music.
